# Web admin

Next.js App Router + TypeScript + Tailwind + komponen bersama bergaya shadcn/ui.
Pratinjau dashboard, pesanan/konfirmasi, menu, tenant, denah, akun dan masuk
pratinjau. Port 3001; pnpm dev dari root menjalankan kedua frontend.

Mode admin/tenant pada header hanya simulasi tampilan, bukan Auth/RBAC. Semua
perubahan data contoh lokal; tidak tersimpan/sinkron ke web-user. Tenant baru draft.
Tidak ada request API, database atau Storage. Rincian:
[frontend-preview](../../docs/frontend-preview.md).
