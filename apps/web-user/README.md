# Web user

Next.js App Router + TypeScript + Tailwind + komponen bersama bergaya shadcn/ui.
Pratinjau katalog, pencarian/kategori, keranjang, checkout, QRIS placeholder,
tracker contoh dan lokasi. Port 3000; jalankan pnpm dev dari root.

Data placeholder satu tenant; checkout contoh memakai schema shared. Tidak ada
pembayaran, API, database, atau realtime sungguhan. State hilang setelah refresh.
Batas lengkap: [frontend-preview](../../docs/frontend-preview.md).
Scaffold asal di folder webkantin tidak diubah.
