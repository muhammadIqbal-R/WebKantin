# Font aplikasi

Aktif: Poppins, Regular 400 / Medium 500 / SemiBold 600 / Bold 700.
Sumber: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/poppins).
Lisensi: [OFL](poppins-OFL.txt). Berkas asli tanpa modifikasi, diambil 2026-11-14.

oleh layout aplikasi aktif. Masing-masing tetap menyertakan lisensinya.
